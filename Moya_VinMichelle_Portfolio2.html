Projects

Cryptocurrency Price Forecasting Using Long Short-Term Memory (LSTM) Networks

Developed a deep learning model using LSTM and 1D CNN layers to forecast cryptocurrency prices based on time-series data. Integrated technical indicators (e.g., RSI, MACD, Bollinger Bands) for feature enrichment and used sliding windows for sequence prediction. Applied standard scaling, log transformation, and model optimization techniques such as early stopping and learning rate scheduling to improve performance.

Arduino-Based Prototype: Flood Detection System Using Ultrasonic and Soil Moisture Sensors

Developed a flood detection prototype using Arduino, ultrasonic sensors, and a soil moisture sensor to detect rising water levels and ground saturation. The system provides real-time visual alerts using red and green LED indicators to signal potential flood conditions..
